This is the first post. I wanted somewhere low stakes to write things down, so this is that.

## how it works

Every post is a markdown file in a `posts/` folder. To publish one, I add a file and push:

```
posts/2026-11-08-my-next-thought.md
```

The top of the file looks like this:

```
---
title: my next thought
date: 2026-11-08
---
```

That is the whole system. No database, no login, no dashboard.

## the rules

- Half-finished is fine.
- Short is fine.
- Wrong is fine, and I can edit it later.
